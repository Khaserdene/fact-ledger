# Fact Ledger (Үнэний Бүртгэл) — Баримт Баталгаажуулалт болон Профайлингийн Платформ

Цахим нийтлэл болон эх сурвалжуудаас олон нийтийн зүтгэлтэн, улс төрчдийн мэдээллийг ялган авч, SHA-256 хэш алгоритмаар эх текстийн бүрэн бүтэн байдлыг баталгаажуулах, он цагийн хэлхээс (timeline) болон мэдлэгийн граф (Knowledge Graph) ашиглан мэдээллийн зөрчлийг илрүүлэх аналитик систем.

---

## 1. Ерөнхий архитектур болон зарчим

Платформ нь дараах үндсэн гурван зарчим дээр тулгуурлан ажиллана:

1. **Эх сурвалжийн баталгаажуулалт (Source Authenticity):** Нийтлэлийн текстийн агуулгыг SHA-256 хэшээр баталгаажуулж, дараах туслах элементүүдийг (аудио, видео, реклам, динамик скрипт) хасан каноник текст хэлбэрээр хадгална.
2. **Баримтын бүтцийн ялгалт (Structured Extraction):** Мэдээллийг `biographical` (намтар, боловсрол, суурь мэдээлэл) болон `chronological` (он цагийн үйл явдал, мэдэгдэл, албан тушаал) гэсэн үндсэн хоёр ангилалд хуваан бүртгэнэ.
3. **Граф болон зөрчлийн шинжилгээ (Graph & Contradiction Analysis):** Субъектуудын хоорондын хамаарал, албан тушаалын хэлхээс болон цаг хугацааны хувьд зөрчилтэй мэдэгдэл, фактуудыг интерактив граф болон зөрчил илрүүлэгч модулиар хянана.

## 3. Системийг суулгах болон ажиллуулах

### Шаардагдах орчин
- **Python:** 3.10+ (Зөвлөмж: 3.14)
- **Node.js:** 18.0+
- **Package Manager:** npm 9.0+

### Хурдан ажиллуулах
Windows орчинд `start.bat` файлыг ажиллуулснаар Backend (Port 8020) болон Frontend (Port 5200) сервисэнүүд автоматаар асаж, браузер нээгдэнэ.

```cmd
start.bat
```

### Гараар суулгах болон ажиллуулах

#### Backend тохиргоо:
```bash
cd backend
python -m venv venv
# Windows:
venv\Scripts\activate
# Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn main:app --host 127.0.0.1 --port 8020 --reload
```
- **API Swagger Баримт бичиг:** `http://127.0.0.1:8020/docs`

#### Frontend тохиргоо:
```bash
cd frontend
npm install
npm run dev
```
- **Системийн веб хаяг:** `http://localhost:5200`

## 4. API Төгсгөлийн цэгүүд (Endpoints)

| Арга (Method) | Төгсгөлийн цэг (Endpoint) | Тайлбар |
|---|---|---|
| `POST` | `/api/scrape` | Оруулсан URL-аас веб текстийг уншиж цэвэрлэх |
| `POST` | `/api/sources` | Шинэ эх сурвалж/нийтлэл баталгаажуулж хадгалах |
| `GET` | `/api/sources/{id}` | Эх сурвалжийн дэлгэрэнгүй болон холбогдох фактууд |
| `GET` | `/api/entities` | Субъектуудын жагсаалт болон шүүлтүүр |
| `POST` | `/api/entities` | Шинэ субъект үүсгэх |
| `GET` | `/api/entities/{id}` | Субъектийн профайл, намтар, цаг хугацааны шугам |
| `GET` | `/api/entities/{id}/facts` | Субъектод хамаарах баримтууд |
| `POST` | `/api/entities/{id}/import-facts` | Баримтуудыг нэгтгэн импортлох (Давхардал алгасна) |
| `GET` | `/api/graph` | Мэдлэгийн графын зангилаа (Nodes) болон холбоосууд (Edges) |
| `GET` | `/api/contradictions` | Илэрсэн баримтын зөрчлүүдийн жагсаалт |

## 5. Техникийн онцлог болон алгоритмууд

### 5.1. Текст цэвэрлэгээ ба Хэш тооцоолол (`hasher.py`, `scraper.py`)
- Wikipedia линкүүдэд `Special:Export` XML API ашиглан 403 алдаанаас зайлсхийнэ.
- Вэб хуудасны HTML бүтцээс зөвхөн агуулгын текстийг `BeautifulSoup` ашиглан ялгана.
- Текстийн SHA-256 хэшийг тооцоолохдоо зай, форматын зөрүүг арилган каноник хэлбэрт оруулж хэшдэх тул вэб хуудасны загвар өөрчлөгдсөн ч эх текст баталгаажсан хэвээр байна.

### 5.2. Огнооны нэгдсэн стандарт (`main.py` -> `_parse_fact_date`)
Төрөл бүрийн форматаар ирэх огнооны мэдээллийг ISO-8601 стандартын дагуу хөрвүүлэн хадгална:
- `YYYY` -> `YYYY-01-01`
- `YYYY-MM` -> `YYYY-MM-01`
- `YYYY-MM-DD` -> `YYYY-MM-DD`

### 5.3. Граф визуалчлал (`KnowledgeGraph.jsx`)
- `d3-force` алгоритмаар зангилаануудын байрлалыг тооцоолно.
- Субъектийн төрлөөс хамаарч өнгөний ялгарал хийгдсэн (УИХ: Ягаан, Засгийн газар: Bleached Red/Pink, Нам: Шар, Компани: Оюу ногоон, Хүн: Цэнхэр).
- Hover болон Click үйлдэлд зангилаануудын хамаарах холбоосууд, харилцааны шошго болон цаг хугацааны хязгаар динамикаар харагдана.
